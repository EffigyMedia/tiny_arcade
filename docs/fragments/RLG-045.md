### RLG-045 — The bend fix was never verified in view

- Description: `rebuildBend()` integrates the visual bend over a span measured from `curveSegs` -
  the ENDLESS road's segment list, which a circuit never fills. On Raceway the span was one step,
  the bend cache held a single entry, **and the road rendered dead straight on every circuit.** The
  map was right and the physics were right; the car was shoved sideways by a curvature the picture
  never showed. `CFG.roadSpan()` now supplies a lap and a half.
- **The fix is in the code and it was never seen.** The frozen entry says so plainly: the probe for
  jumping the car to a point on the lap did not move it, so every screenshot still showed the start
  line. The bug and the fix are both certain; the picture is not.
- Intent: This is the single largest visual claim in the driving engine and nobody has looked at it.
  A harness now exists that drives for 30 seconds, so the picture is reachable in a way it was not
  when the fix was written.
- Done when: a screenshot taken mid-corner on a generated circuit shows a bent road, and it is
  attached to this item.

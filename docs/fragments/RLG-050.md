### RLG-050 — One cabinet tap, one launch path

- Description: Two click handlers answered every cabinet tap in the launcher. The live one
  navigates to `data-href` after 130 ms. The other predates the change from `<a href>` cabinets to
  `<div>` cabinets: it reads `getAttribute('href')`, gets `null`, and schedules
  `location.href = null` at 210 ms. Deleted, with a note in its place.
- **The audit that found it was wrong about what it does, and the report now says so.** AUD-001 was
  written as Critical and as the explanation for the owner's field report of friends getting 404s.
  Measured on the real click path while fixing it:
  - **Both handlers fire.** Instrumenting `setTimeout` recorded `[130, 210]` from one tap, and the
    attribute really is `null`.
  - **The stray navigation does not win.** With the cabinet's response held 600-800 ms, so the
    launcher outlived the 210 ms timer, exactly ONE navigation happened and it went to the cabinet.
    Chrome ignores a second `location` assignment while one from that document is pending.
- So the reproducible harm is a duplicated coin jingle on every tap and a dead path, not a 404.
  Severity dropped to High; the field report stays explained by [[RLG-049]].
- **The guard took three attempts and the first two were worthless**, which is the part worth
  keeping. `smoke-test.py` now opens the launcher, opens a shelf and taps a cabinet - a Must-flow
  with no coverage at all until now. But asserting WHERE the tap lands cannot see this defect: on a
  fast local server the real navigation wins, so the check passed with the bug reintroduced. CDP
  throttling did not help either - it does not slow a main-frame navigation.
- **It asserts the invariant that actually broke: one tap schedules ONE launch.** Timers are
  neutered, the tap is counted, the clock is restored, and the tap is repeated for real to check
  the landing. **Proven in both directions before shipping**: with the dead handler restored it
  fails with `2 timers: [130, 210]`; without it, it passes.
- Also in this unit: the cabinet keydown handler claims the space key, which used to scroll the
  rack while launching.
- Verified: 18/18 cabinets plus the launcher check; build gate green.

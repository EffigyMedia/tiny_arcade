### RLG-010 — Curate seeded circuits instead of generating them live
- Description: `buildCircuit(league, seed)` is deterministic, so the same seed always builds the same
  circuit. Generate thousands offline, drive them with the harness, and ship a list of the good ones.
- Intent: This is the third option between authored tracks and procedural ones, and it takes the
  strengths of both. Authored tracks cost a designer per track. Pure generation ships whatever the
  generator produced, including the circuits that are dull or broken. **Curation ships generated
  tracks that a human approved**, and it costs nothing at runtime because a seed is a number.
- Depends on: [[RLG-002]]. A curation pass that ranks circuits before corners matter would rank them
  on the wrong thing, and the whole list would have to be thrown away.
- Done when: an offline script generates and scores circuits with the harness, and the game ships a
  list of approved seeds per league.
- **RULED 2026-08-23T23:59:14-04:00** — AMENDED 2026-08-23 - THE HARD HALF IS DONE AND THE SHIPPING HALF IS NOT. The generator is **deterministic**: `buildCircuit(league, seed)` is a pure map from a number to a track, verified in the frozen log - seed 12345 twice gives 819,720 units and 28 corners both times. A curation trial ran over 120 seeds and 118 passed on zero crossings and aspect under 1.45. **A track is now a number**, which turns the generator from a runtime feature into an authoring tool. WHAT IS NOT DONE: `buildCircuit(league)` is still called with no seed, so every race is a fresh random track and nothing ships a `TRACKS` list. Until it does, the curation buys nothing at runtime. **And this is the item the last two passes of work quietly depend on:** sector bests, the live delta, qualifying and lap records are all about improving on a track you KNOW. A lap record on a circuit you will never see again is meaningless, so procedural generation is undermining the features built on top of it. Done when: a curation run of a few thousand is judged on crossings, aspect, corner mix and lap time, and a named `TRACKS` table of the survivors ships. The generator stays; it just stops running while you play.

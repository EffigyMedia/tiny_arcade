### RLG-006 — The start line, and the lights
- Description: Raceway has no visible start line and no start sequence. The car simply begins to
  move at a rolling start in second gear.
- Intent: The countdown sound was built weeks before the standup and it is already five reds and a
  go. It was written for a clock that runs out, and it belongs here. The art and the sound both
  exist in part, so this is assembly rather than invention.
- Done when: a start line is drawn on the circuit, a light gantry counts down with the existing
  sound, and the race starts on the lights.

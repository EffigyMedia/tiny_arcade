### RLG-029 — Arcade.haptics - vibration with a no-op fallback
- Description: A thin wrapper over `navigator.vibrate` that does nothing where the device or the
  browser does not support it.
- Intent: The smallest item on the shared backlog. It matters because every machine that wants
  haptics would otherwise write the same capability test.
- Done when: the helper is on the shell and one machine uses it.

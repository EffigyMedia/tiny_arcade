### RLG-001 — The arcade as adopted at v0.9.0
- Description: The baseline this project entered the Code Continuum process with. Eighteen machines
  on three shelves, a shared shell, a synthesized audio engine, a service worker, a self-hosted font
  set, and a 9,849-line driving engine that serves two games. About 21,000 lines and 220 commits.
- Intent: The process needs one item that says what already shipped. Every machine on the floor was
  built before the store existed, and to write a fragment for each one after the fact would invent a
  record rather than keep one. This item is the record: the state is described in
  `docs/core/tiny_arcade_design.md`, and everything from here forward gets its own fragment.
- What is on the floor: Golden Era (14) - Ribbit, Swarm, Popshot, Phalanx, Ricochet, Soviet Blocks,
  Ziggurat, Vector, Aegis, Burrow, Coil, Feather, Girder, Penboy. Effigy Originals (2) - Deep,
  Derelict. The driving pair (2) - Highway, Raceway.
- Where the rule "no feature ships without an item" starts: the next unit of work after this one.
- Source: the standup on 2026-08-23. See `docs/reference/DRIVING.md` for what is built inside the
  two driving games, and `docs/reference/DESIGN.md` for the decisions behind each machine.

### RLG-015 — A track-limits penalty
- Description: All four wheels off the circuit and the lap does not count. Nothing enforces the edge
  of the road today.
- Intent: A lap time that a player set by cutting a corner is not a lap time. This matters most for
  qualifying ([[RLG-004]]) and for the sector bests ([[RLG-005]]), which are both records that a cut
  corner corrupts silently.
- Depends on: [[RLG-002]]. A limit on a circuit that nobody has to brake for is a limit nobody
  reaches.
- Done when: a lap with all four wheels off the road is marked invalid and does not set a record.

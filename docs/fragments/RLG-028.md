### RLG-028 — Arcade.scores - a local top-ten table with initials
- Description: A local top-ten score table with initials entry, and one shared results screen.
- Intent: Very arcade, and it makes the save layer earn its keep. Today a machine keeps one best
  score and the launcher prints it on the cabinet card; a table makes a run compete with the runs
  before it.
- Done when: any machine can post a score to a shared table, and the results screen is one
  implementation rather than one per machine.

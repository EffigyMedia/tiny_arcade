### RLG-022 — A license file, and the font licenses beside it
- Description: The repository is public and carries no `LICENSE` file. The font licenses exist at
  `fonts/LICENSES.md` and cover the typefaces.
- Intent: The product is intended for sale, and a public repository with no license grants nothing
  and states nothing. The font licenses already ship; the product's own terms do not.
- This is the owner's call: the license text is a commercial decision, not a technical one.
- Done when: a `LICENSE` file states the terms, and the packaged build ships it beside the font
  licenses.
- **RULED 2026-08-23T22:49:54-04:00** — BUILT 2026-08-23. OWNER DECISION: an all-rights-reserved notice, and the repository stays public. **The capability that had to survive is the hosting.** GitHub Pages serves this repository, and a private repository does not get Pages on the free tier - so a license that forced the repository private would cost the product its host to protect source that is client-side JavaScript and readable in any browser anyway. **What the notice buys is not secrecy. It is the end of ambiguity.** No license at all is legally murkier than a restrictive one: a reader has no stated terms, and a takedown has nothing to point at. The notice states the terms that every source header in this repository already claimed - `(c) 2026 Effigy Media. All rights reserved.` - and grants play, reading, and a private copy while withholding redistribution, rehosting, reuse in another product, and sale. **Two carve-outs are in it because both would otherwise be read wrongly.** The fonts are third-party works under open licenses that permit redistribution, so the notice says plainly that they are not covered and points at `fonts/LICENSES.md`. And the clone shelves needed a sentence: the notice covers what Effigy Media made, and it states that no sprite, palette, layout, character design, or trademark of any other party is reproduced. **That sentence is not a defense and it is not meant as one** - the exposure on the clone shelves is a distribution question, and [[RLG-023]] owns it. It exists so that a reader does not take the notice as a claim over the machines these descend from. The file ships in the distributable: it is on the packer's whitelist, so a downloaded build carries its terms beside the font licenses.

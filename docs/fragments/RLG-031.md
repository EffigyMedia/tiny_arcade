### RLG-031 — Arcade.tilt - device orientation, including the iOS permission dance
- Description: Device-orientation input on the shell, including the iOS `requestPermission()`
  gesture sequence that a page must perform before it gets any reading.
- Intent: Only one queued machine needs it, and that machine is held for last by decision, so this
  is the final piece of shared engine work. It carries the most technical risk on the backlog.
- Done when: the helper is on the shell, it asks for permission from a real gesture, and it degrades
  to nothing where the device has no sensor.

### RLG-026 — Arcade.grid - the shared tile map helper
- Description: A tile map helper on the shell: draw, collide, and A-star pathfind. Derelict holds a
  private version that is worth the lift.
- Intent: Three queued machines need it - Penboy, Fuse, and Horde. The shared rule is to build a
  helper **when the first machine that needs one arrives**, not before, but to design it for the
  second and the third.
- Done when: the helper is on the shell, Derelict uses it instead of its private copy, and the
  private copy is gone.

### RLG-004 — Qualifying, and the grid it feeds
- Description: A hot lap that sets the starting position on the grid. It is the time-trial loop with
  a different result screen.
- Intent: The cheapest large win on the Raceway list. **The title screen already draws a grid, so
  the game promises this and does not deliver it.** A start position that the player earned makes
  the first corner mean something.
- Depends on: the end card ([[RLG-003]]) is where a qualifying result is shown, so that item lands
  first or with it.
- Done when: a qualifying lap runs before a race, its time sets the grid position, and the grid the
  title screen draws is the grid the race starts from.

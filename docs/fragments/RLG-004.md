### RLG-004 — Qualifying, and the grid it feeds
- Description: A hot lap that sets the starting position on the grid. It is the time-trial loop with
  a different result screen.
- Intent: The cheapest large win on the Raceway list. **The title screen already draws a grid, so
  the game promises this and does not deliver it.** A start position that the player earned makes
  the first corner mean something.
- Depends on: the end card ([[RLG-003]]) is where a qualifying result is shown, so that item lands
  first or with it.
- Done when: a qualifying lap runs before a race, its time sets the grid position, and the grid the
  title screen draws is the grid the race starts from.
- **RULED 2026-08-23T23:58:45-04:00** — BUILT - SEEDED FROM A STALE DOCUMENT AND ALREADY DONE. Verified in code on 2026-08-23; `games/sw/raceway.html` carries the QUALIFYING block and a QUALIFY button above DRIVE. One flying lap on an empty circuit sets the grid, and qualifying ends itself: the first completed lap IS the session, so the lap counter calls `finishQualifying()` and stops the run. Over 200 identical laps the grid slot centres on P5-P6 with pole rare and reachable, and a lap 4% quicker moves most of the way up the sheet. **THE RIVALS DO NOT DRIVE, AND THAT IS THE DESIGN.** Their times are drawn around the player's, biased -3.8% to +5.2%, so a clean lap is rewarded and a scruffy one punished. To simulate eleven cars for a minute would cost a minute of real time and give less control over the spread. **The alternative is a loading screen.** Two seams were added to the engine for it - `CFG.garageButtons()` and `CFG.garageActions(start)`. Highway passes neither and is unchanged.

### RLG-030 — Arcade.sticks - an on-screen twin-stick overlay
- Description: An on-screen twin-stick control overlay, drawn by the shell.
- Intent: Grid Riot needs it and cannot be built without it. Vector may want it.
- Depends on: nothing built. It may also want landscape support ([[RLG-032]]), because a twin-stick
  machine wants width.
- Done when: the overlay is on the shell, it reports through the same names as the gamepad, and one
  machine drives from it.

### RLG-056 — Dead code swept, and the audio clock guarded everywhere

- **The guarded clock (AUD-013).** Six cabinets reached `AR.audio.ctx.currentTime` directly while
  the other twelve and the launcher use `AR.audio.now()`, which returns 0 rather than throwing when
  no context exists. It only bites where a real gesture happened and `init()` still failed - rare,
  and webview-flavored, which is exactly the environment the design document says is not yet
  verified. All six converted.
- **The sweep (AUD-012).** Each item is small; the point is that each was a small lie to the next
  reader, and this project has already been bitten by one of exactly this kind.
  - The launcher carried a block of `#snd` rules styling a speaker button that no longer exists in
    the markup. **The launcher's own comment records what that class of thing costs**: one stale id
    once blanked the whole page.
  - Coil built a radial gradient, fed it through a ternary whose two branches were the same value,
    and never used it. Deleted rather than repaired - nothing read it.
  - Soviet Blocks and Burrow each had an `if` with an empty body.
  - Ziggurat guarded a collision with `f.kind !== 'disc'`. There is no `disc` foe; the escape discs
    are their own list, so the test was always true.
  - Derelict defined `snd.arc` and `snd.surge` with no callers - survivors of the combat rework
    that deleted the functions they belonged to.
  - The loading panel's comment claimed a 600 ms floor and a 6 s ceiling; the code says 500 ms and
    20 s. The comment now says what the code does.
- Verified: build gate green, 18/18 cabinets plus the launcher check, and the driving pair 21/21.

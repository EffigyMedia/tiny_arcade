### RLG-041 — The launcher at scale - grouping, search, and a credits line
- Description: Three items from the frozen housekeeping list, all of which arrive with the size of
  the catalog rather than with any one machine.
- The three: the catalog file grows long and could be grouped by tier; the rack wants a filter or a
  search once it holds more than about fifteen machines; and each machine could carry a credits line
  on its game-over screen.
- Intent: The launcher builds itself from the catalog and assumes nothing about how many machines
  there are, which is why none of this is urgent. It becomes urgent at roughly twice the current
  count, and both queues ([[RLG-038]] and [[RLG-039]]) point that way.
- Note: the shelves already do most of the work a filter would do. Measure whether the rack is
  actually hard to use before this is built.
- Done when: the rack stays usable at forty machines.

### RLG-020 — There is no doctor command
- Description: The process runs a `doctor` command at every handoff to verify that the environment
  is ready. This project has no such command.
- Intent: A static site has little to verify, which is exactly why the check should be cheap and
  should exist. What it can check: that the catalog parses and that every file it names is present;
  that every machine declares the three meta tags and loads both scripts; that the generated asset
  list holds every machine in the catalog; that the brace balance in the launcher's one style block
  is zero; and that Playwright is installed, so the test command can run.
- Why the brace check is on that list: a stray closing brace in the launcher's style block closes
  the stylesheet early and silently kills every rule below it. It happened once, and the page simply
  lost its layout with no error and no warning.
- Done when: one command runs all of the checks above and exits non-zero on any failure.

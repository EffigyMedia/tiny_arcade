### RLG-032 — Landscape support in the shell
- Description: The shell assumes portrait. It calculates the room from the viewport height and
  injects a 38-pixel title bar on that assumption.
- Intent: Several queued machines want a wide board, and one queued machine is a dogfight game that
  portrait is simply wrong for. Today the answer to any of them is "not without shell work".
- Note: this is not a per-machine decision. If the shell supports landscape, every machine must
  still fit portrait, because portrait is the product's hard constraint.
- Done when: a machine can declare that it wants landscape, the shell lays the bar and the room out
  correctly for it, and no portrait machine changes behavior.

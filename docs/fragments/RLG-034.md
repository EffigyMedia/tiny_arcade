### RLG-034 — Title screens for Penboy, Highway, and Deep
- Description: The title screen specification is fixed and Derelict is built to it: the name of the
  machine and four buttons - PLAY, CONTINUE where a run exists, OPTIONS which houses CONTROLS, and
  QUIT. Nothing else: no flavor paragraph, no legend, no control recap. **Deep has no title screen
  at all and starts cold.**
- Intent: The front door only has to open. The game teaches itself. Three machines out of the four
  that existed when the specification was written still do not follow it, and the machines built
  since inherit whatever they were given.
- The shared parts already exist: `Arcade.home()` reads each machine's `arcade-home` meta tag, so
  QUIT means one thing everywhere, and `Arcade.touch` decides whether CONTROLS lists taps or keys,
  so a phone never reads "press Esc".
- Done when: Penboy, Highway, and Deep each open on a title screen built to the specification, and
  each keeps its own typeface and palette.
- **RULED 2026-08-24T23:36:53-04:00** — BUILT - VERIFIED IN CODE 2026-08-24 during the audit, and this item was stale in the same way the four corrected on 2026-08-24 were. All three title screens exist: Penboy has `showTitle` with PLAY / OPTIONS / QUIT, Deep has the same menu plus an OPTIONS-to-CONTROLS chain, and Highway is served by the engine's own title at `road.js`. **The half of this item that was genuinely open is now closed by a different route**: it also asked that the four buttons behave the same everywhere, and until [[RLG-052]] a keyboard or a pad could only ever press the FIRST of them, so OPTIONS and QUIT were unreachable without a pointer on every cabinet. The shell's menu cursor makes the structure real rather than only drawn.

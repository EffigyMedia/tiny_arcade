### RLG-023 — Decide the commercial shelf split and build it into the packer
- Description: Add a commercial flag to the packer that omits a whole category from the build. Every
  catalog entry carries a shelf field, and the launcher renders its shelves from it, so a build
  without the clone shelves comes up with the shelves it does have and no dead links.
- Intent: The frozen note is blunt about why this is cheap now and expensive later: **to do it
  before a release costs nothing; to do it after a complaint costs a great deal more.** To sell
  clean-room takes on published cabinets is a real risk rather than a theoretical one.
- Depends on: [[RLG-018]], because there is no packer to add a flag to. Also on [[RLG-021]], because
  which machines are Originals is the question the flag answers.
- The rule that keeps this a one-line change: nothing clone-specific ever enters the shared layer.
  The moment shelf-specific code reaches `arcade.js`, `audio.js`, or the launcher, to drop a shelf
  stops being cheap.
- Done when: the packer can build a shelf-restricted zip, and the launcher renders it correctly.

### RLG-035 — Arcade.cinema.play as a shell convention
- Description: Lift the cinematic sequence runner into the shell, roughly as
  `Arcade.cinema.play([{art, text}], {key, onDone})`, with SKIP, once-per-device memory, and the
  replay entry handled by the shell rather than re-implemented per machine.
- Intent: Derelict proved the pattern - canvas scenes drawn at runtime, a frame sequence between the
  title and the run. It should become the first caller instead of the only implementation.
- **Two things were deliberately pulled back out of the shell, and they must not go back in.** A
  shared film grade, which would have given a ballpoint-drawn machine horror-film grain: the tell
  was that it had opinions - a color, a typeface, a dot - rather than that it did work. And the
  sequence runner itself, in an earlier form shaped entirely around one machine's eyebrow text,
  final button label, and aspect ratio: speculative generality with exactly one caller.
- Therefore: **when the second machine wants a sequence, compare the two and extract only what
  genuinely matches.** Until a second caller exists, this item stays requested.
- Done when: two machines run cinematics through one shell primitive that has no opinions about
  either one.

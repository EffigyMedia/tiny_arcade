### RLG-003 — The end card shows the session
- Description: The driving games record qualifying, sector bests, lap times, and grid position, and
  then throw all of it away. The end card shows none of it.
- Intent: **The highest value per hour on the whole list**, because the data already exists and the
  work is display. A race that measures a player's lap and never shows it back has done the
  expensive half and skipped the cheap half.
- Where it lives: the end card is one of the three screens built by string concatenation into
  `openVeil(html, handlers)`.
- Done when: the end card shows lap times, the best lap, the sector bests, and the grid position for
  the session that just ended.
